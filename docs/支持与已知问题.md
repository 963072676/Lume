# 支持与已知问题

## 平台与验收边界

目标平台为 Windows 10 2004+ / Windows 11 x64；不提供 ARM64 原生包、macOS 或 Linux 版本。最低系统声明来自构建目标，不等于所有 Windows 版本均经实机测试。

| 场景 | 当前预览源码的验收范围 |
| --- | --- |
| 核心规则、迁移、完整备份/恢复、归档容错、并发和脱敏日志 | 自动回归 |
| 启动项迁移与托管图层隐藏/恢复 | 独立注册表键及屏幕外窗口的 16 项检查；不改真实启动项和桌面 |
| 菜单、图标、主界面、目录事件风暴及失联恢复 | CI 非交互验收；不代表完整 Explorer 桌面 |
| 回收站空/满图标 | 空满资源及真实 Shell 通知配合注入计数的屏幕外验收；未在用户桌面实际清空回收站 |
| 文档、PDF、媒体预览、AI 模拟界面与视觉检查 | 本地 Windows 11 非交互验收通过；服务器 CI 显式跳过并记录 |
| 原生保护进程 | 屏幕外窗口正常/异常退出等 8 场景 |
| 慢 Shell / 快捷目标进程隔离 | 28 项非交互检查，含故意挂起、崩溃、排队超时、取消、父进程退出、空闲回收与 Dispatcher 响应；不接管真实桌面 |
| 过期引用检测、备份、清理、重启/归档撤销 | 核心回归与 22 项虚构文件/屏幕外控件检查；不清理真实用户数据 |
| 大目录查询和控件复用 | 同机 1 万文件基准、核心行为回归、1,000 项真实事件与本页控件/选择检查 |
| 快速操作的后台查询、取消与过期结果 | 18 项屏幕外面板检查；不模拟真实键盘输入 |

| 媒体预览控件生命周期 | 包含在非交互功能验收中；不等于所有媒体格式均已验收 |
| Explorer 重启、真实休眠唤醒 | 待实机验收 |
| 多显示器插拔、混合缩放 | 待实机验收 |
| 8 小时常驻稳定性 | 发布时尚无完整通过结论；旧构建的观察不作为本版验收 |
| 跨卷归档、OneDrive 等云文件、外部 AI | 按实际环境单独验证；物理归档拒绝云占位路径及链接 |

## 常见问题

Windows Server 不在当前支持范围。Server 2022/2025 自动构建机的功能预览验收进程在完成检查后异常退出（`ntdll.dll / 0xc000000d`），排除媒体控件后仍可复现，根因未确定。CI 显式跳过该阶段并记录覆盖范围；本地 Windows 11 同一套检查通过。该差异仍需定位，不能将 CI 成功解释为预览在所有 Windows 环境可用。

- 关闭管理窗口后仍在运行：这是托盘常驻行为。彻底退出请使用托盘菜单。
- 精简版不能启动：安装 .NET 10 Windows Desktop Runtime x64，或改用完整包。
- 原桌面图标没有恢复：先从托盘退出并等待保护程序；检查 Windows 桌面右键 → 查看 → 显示桌面图标。仍异常时保留诊断并报告，必要时在结束当前文件操作后重启资源管理器。
- 文件没有出现在分区：只扫描关注目录第一层，先检查关注目录、规则和扫描提示。普通归类不移动原文件。
- 无法撤销或恢复：不要手动删历史分段；恢复配置不等于恢复物理归档后的文件位置。
- 规则计算超过时间限制：默认采用 2 秒整批计算限额，超时结果不提交。简化复杂正则或减少规则后重新刷新；不支持线性匹配的环视/后向引用继续使用 50 ms 单次限制。这个边界不限制目录扫描或 Shell 请求。
- 完整备份期间数据变化：为避免配置与历史不一致，本次备份会失败并保留原数据，等待当前操作完成后重试。数据上限 512 MiB / 10,000 个文件，备份保存到数据目录之外。
- 归档记录无法读取：程序会优先读取有效备份并保留损坏原件；没有有效备份的单条日志跳过，其他记录仍可使用。人工核查后再处理记录，程序不会因此删除或移动真实文件。
- 部分图标显示备用图案或提示快捷目标读取未完成：工作进程请求有 3 秒限额，失败后冷却 5 秒；图标失败缓存 5 秒，后续加载可重试。快捷目标整批预算 8 秒，超过时保留文件、有效旧目标和已有归类，完整扫描会重试。工作进程空闲 10 秒后退出，再次加载会有启动开销。详见[Shell 请求隔离](Shell请求隔离.md)。
- 隔离范围为快捷目标、图标和缩略图的提供程序调用。目录枚举/基础文件元数据、用户主动打开的内容预览、原生右键菜单仍有各自边界；本版不宣称所有网络目录和第三方提供程序都可强制取消。
- 首次引用检测没有候选：从首次确认缺失开始等待，默认 30 天；只处理当前关注目录中的自动归类记录和学习样本。手动固定、排序、外部引用及无法确认路径保留，完整规则见随包《过期引用清理.md》。
- 清理后磁盘占用没有下降：清理减少当前状态的记录，完整备份和撤销历史保留原数据。不要直接删历史依赖；清理后格式升级为 3，回到 beta.1–beta.4 需恢复清理前完整备份。

## 卸载

先在设置中关闭开机启动、关闭已启用的桌面菜单集成，再从托盘退出。确认桌面恢复后删除程序目录。数据默认保留在 `%LOCALAPPDATA%\Lume`；确认不再需要归档恢复记录并完成备份后，可自行删除。删除程序或配置不会把已归档文件自动移回桌面。

## 报告问题

请提供程序版本、Windows 版本、显示器数量/缩放、复现步骤和时间；设置页可导出脱敏诊断。上传前检查内容，不上传真实配置、密钥或含路径的历史导出。文件误操作或密钥泄露请使用 SECURITY.md 中的私密报告入口。
