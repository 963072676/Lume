# Lume 0.1.0 使用说明

## 启动与退出

完整便携版解压到普通文件夹，运行 Lume.exe。保留原生菜单 DLL 和 shell-extension.txt。
程序默认在桌面显示分区；Win+D 查看。双击托盘图标进入主窗口；关闭主窗口继续驻留。
托盘菜单可暂停、归档、打开此电脑/回收站及退出。暂停或退出后恢复 Windows 原桌面图标。

普通版不需要另装 .NET。名称含 lite 的精简包需 .NET 10 Windows Desktop Runtime x64。
启动新版前退出正在运行的旧版；单实例机制不会让两版同时管理桌面。

## 找文件与归类

主窗口左侧为分区列表，选择分区缩小范围；“全部文件”按当前全部/工作/演示视图显示。
“待整理”只显示临时收件箱。搜索作用于当前视图与选中分区；Ctrl+K 可跨关注目录找文件。
双击打开，空格预览。快捷方式隐藏 .lnk/.url 后缀，鼠标提示保留真实路径。

Ctrl 点击多选，Shift 按显示顺序选范围，Ctrl+A 选择本页，Ctrl+Shift+A 或 Esc 清空选择。
桌面各分区与主窗口分别维护选择，换页/筛选后取消不可见项。
拖到桌面分区或主窗口左侧分区名称，或者右键“归入分区”，完成归类；原文件仍在原位置。
从资源管理器拖入也只建立引用。映射和最近文件分区由目录内容决定，不接受手动归类。
Delete 或右键“移入回收站”会在一次确认后删除选中项目，恢复请使用 Windows 回收站；历史撤销不恢复回收站文件。

大列表每页 80 项，底部可翻页，搜索涵盖当前范围所有页；没有截断数据。Ctrl+A 仅本页。
同分区单个文件可拖动重排，多选文件可拖到其他分区；最近文件始终按时间排列。

## 桌面分区

拖动标题移动，八方向调整大小，布局自动保存。双击标题或点折叠按钮收起；锁定按钮固定位置和大小。
更多菜单保留分区内搜索、排序、图标大小、移到下一显示器、重命名、物理归档、设置和解散分区。
“解散分区”只删除分区及相关规则，保留文件；可从历史撤销。
拖动吸附支持对齐线，按 Alt 临时关闭。设置的分区页可统一排列、备份/恢复、折叠/展开、调整大小和底色。
Windows 系统入口遵循系统桌面图标设置，设置的常规页可控制是否显示。

## 规则与 AI

规则按列表从上到下匹配，首个命中生效；手动归属优先。可创建、编辑、启停、调整顺序和删除。
保留扩展名、名称、大小、日期、来源、文件类型、路径与快捷目标条件；保存前可预览命中。
多次相同手动归类形成的习惯建议在规则页展示，需要确认才转为自动规则。

AI 整理需要服务地址、API Key 和模型。可获取模型列表或手动填写；密钥通过 Windows 当前用户加密保存。
默认发送文件名称、应用信息与分区信息，不发送完整路径、文件正文或桌面截图；“包含完整路径”可主动开启。
支持归类偏好、仅收件箱、包含手动固定项目，分析中可取消。
先检查建议、调整目标分区，再应用勾选项；应用为一次可撤销的虚拟归类。
分析后文件/归属变化会拒绝旧建议，避免覆盖新操作。规则编辑器也保留 AI 生成条件和本地多媒体模板。

## 归档与恢复

从更多菜单、快速操作、桌面分区或托盘进入物理归档。选择分区、文件年龄、目标和是否按月建子目录，先生成预览再确认移动。
仅普通文件可归档，不覆盖同名项；链接、目录联接与云占位路径拒绝物理操作。
归档日志独立保存；整理历史提供恢复原位置入口。原位置出现新同名文件时不会覆盖。
普通归类、规则变更等通过历史最近一步撤销；Ctrl+Z 在文件视图也可撤销。

## 设置与数据

- 常规：Windows 系统入口、开机启动、桌面右键集成。
- 分区：排列、布局备份/恢复、折叠、工作/演示可见性、重命名/删除、图标大小、吸附、底色。
- 目录：文件夹映射、最近文件、关注目录增删。
- AI 与数据：AI 配置、打开本地数据、备份说明与快捷键。

真实配置位于当前用户 LocalAppData 的 Lume 目录；每次保存保留上一份 .bak。状态版本保持 1，兼容已有分区、规则、布局、历史和 AI 配置。
演示使用程序旁 demo-data，不修改开机启动与桌面菜单，但 `--demo` 仍会临时挂载真实桌面。

## 快捷键与菜单

Ctrl+K 快速操作，支持文件/分区/动作搜索，输入 > 只找动作；↑↓ 选择，Enter 执行，Esc 关闭。
Ctrl+F 搜索当前视图；Ctrl+Alt+1/2/3 切换全部/工作/演示。
Windows 11 在桌面右键“显示更多选项”里进入 Lume；菜单收为 7 项，其余操作在 Ctrl+K 和设置中。

## 限制

只扫描第一层，超大目录仍需完整扫描元数据；分页控制界面控件量，不等于全盘索引。
静态壁纸采样柔化，动态壁纸不逐帧模糊；没有定时归档、全局系统快捷键或自动更新。
模型效果取决于实际服务；多显示器热插拔、Explorer 重启与跨卷归档需按使用环境验证。
