# Lume 0.2.0-beta.10

此预览版减少超大目录下多张桌面卡片刷新时的重复查询。卡片各自的搜索、排序、分页和选择行为继续保留。

- 桌面卡片创建及整批刷新共用一次文件分组；同一批中的相同视图和搜索词共用筛选结果。卡片自身搜索和翻页仍能单独更新，不保留历次搜索结果。
- 同机 Windows 11 / .NET 10.0.11、Release、7 次采样，十万合成文件 / 30 普通卡片无搜索刷新所用的核心调用从 498.39 ms / 62,336,344 B 临时分配降至 46.37 ms / 4,802,096 B（59.45 → 4.58 MiB）；混合独立搜索从 484.60 ms / 62,613,008 B 降至 55.37 ms / 5,075,088 B。
- 这些数字衡量核心查询调用，不包含真实桌面渲染，也不推导进程总内存的同等下降。索引和排序分别保持 25,000 项长期引用上限，超大目录只在本批临时处理。
- 新增 5 项核心回归和 4 个批次性能场景，共 179 项核心检查、27 个性能场景；名称排序按当前区域断言，并在中英文区域复核。17 项实际卡片控件检查验证初始化、独立搜索/排序、分页、折叠/展开、元数据、删除和选择；没有显示窗口、创建桌面句柄、请求焦点或模拟输入。
- 初始化结果首次加载后释放，不被随后加载沿用。保留 beta.9 的系统支持更正与 CI 依赖维护，以及 beta.8 的辅助属性和执行入口。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。系统支持范围见随包《支持与已知问题.md》，下载校验和 GitHub 来源证明见《验证下载.md》。来源证明不替代 Windows 代码签名。

仍为预览版。真实 Explorer 重启、休眠、多屏 / 混合缩放、读屏与键盘焦点，以及完整 8 小时常驻验收尚未完成；进行中的长测不计作通过。稳定版保持 0.1.0。本轮未升级或重启用户正在使用的程序。
