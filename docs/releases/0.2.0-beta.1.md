# Lume 0.2.0-beta.1

这是公开预览版，提供新主题、原生 Windows 图标菜单，以及扫描、排序、保存和后台占用优化。

- 目录增量扫描与快捷方式缓存，无变化时跳过界面重建。
- 手动排序使用索引；设置与历史分开保存。
- 新增轻量原生恢复保护程序、配置备份恢复、脱敏诊断导出。
- 新增可复现性能检查、非交互 WPF 自动验收及带构建信息的完整/精简包。

## 下载

Windows x64：完整 ZIP 自带运行时；`-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。保留全部解压文件，尤其是 `Lume.Guard.exe`。ZIP 的 SHA-256 见同名 `.sha256` 附件。

## 升级前必读

先从托盘退出，备份整个 `%LOCALAPPDATA%\Lume`，保留旧程序。新版本首次保存迁移到状态格式 2；旧程序不能直接读取。回退需要升级前整目录备份，升级后新增记录仅保留在新格式备份中。配置回退不会撤销真实文件移动。

详细步骤见 [升级与回退](https://github.com/963072676/Lume/blob/v0.2.0-beta.1/docs/升级与回退.md)。

## 验收边界

发布流水线须通过核心、原生恢复、非交互 WPF、目录恢复及性能检查才会生成本发布。它们不等于真实 Explorer 接管、休眠唤醒、多屏插拔/混合缩放或完整 8 小时常驻验收；上述项目仍待完成。因此保留预览状态，稳定版仍为 0.1.0。

CI 使用软件渲染，检查核心、原生恢复、菜单、图标、主界面、目录恢复与性能。功能预览验收在本地 Windows 11 通过；Server 2022/2025 构建机在该阶段完成检查后退出时触发 `ntdll.dll / 0xc000000d`，根因未确定，因此 CI 显式跳过并记录该阶段，不能计作 CI 通过项。Server 不在本版支持范围。

问题报告请附版本、环境、复现步骤和经过检查的脱敏诊断，不要公开配置、历史导出、密钥或文件正文。
