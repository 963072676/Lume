# 性能复测

在与构建相同的 Windows / PowerShell 7 环境运行：

```powershell
./scripts/benchmark.ps1
./scripts/verify.ps1 -SkipInteractive
```

第一条写出 `artifacts/benchmark.json`，使用虚构数据，预热 2 次并测量 7 次中位数。记录系统、运行时、处理器数量、耗时及当前线程托管分配，不包含个人路径。共 7 个场景：排序 5,000/10,000 项，设置保存 0/1,000 条历史，5,000 项 / 30 条规则的预处理逐项和批量分类，以及 100 项回溯压力正则。每场景耗时上限 1 秒；排序分配上限 32 MiB，设置保存上限 1 MiB，规则场景上限 4 MiB。这些是捕获明显退化的宽松自动检查边界，不是面向所有电脑的性能承诺，也不代表进程总内存。

对比优化前后时使用同一电脑、构建配置、SDK 和数据规模，保留两份结果；不要把不同 CI 机器的毫秒差异当作产品提升。降低阈值前先收集多个环境的结果。

第二条还包含 28 项工作进程验收，结果为 `artifacts/verification-0.2.0-beta.4/shell-worker-result.json`。其中记录一次工作进程临时私有内存、挂起请求耗时及排队请求期限；用进程实际退出和后续重启判断恢复，不能只根据 `Task` 已返回判断。工作进程空闲退出后不再占用常驻内存，读取期间有额外进程开销；测试样本不代表真实桌面全部进程的内存变化。隔离边界见[Shell 请求隔离](Shell请求隔离.md)。

第二条检查启动项和图层身份、隐藏属性变化、搜索合并、真实目录事件风暴、失联恢复、无变化刷新等行为。长测先运行 `./scripts/start-soak.ps1 -Minutes 480` 创建隔离运行，再用 `./scripts/check-soak.ps1 -RunPath <run.json路径>` 核验进程身份、哈希和最终结果。没有最终结果不算通过；睡眠或停顿不按正常观察时长累计。

目前长测记录内存和句柄，但尚未建立跨环境的泄漏趋势判定标准。完整性能验收仍应补充真实桌面空闲 CPU、内存/句柄趋势及多屏操作响应。屏幕外验收不能代替这些测量。
