# 性能复测

在与构建相同的 Windows / PowerShell 7 环境运行：

```powershell
./scripts/benchmark.ps1
./scripts/verify.ps1 -SkipInteractive
```

第一条写出 `artifacts/benchmark.json`，使用虚构数据，预热 2 次并测量 7 次中位数。记录系统、运行时、处理器数量、耗时及当前线程托管分配，不包含个人路径。共 13 个场景：排序 5,000/10,000 项，设置保存 0/1,000 条历史，1 万文件在 5/30/60 个分区的首次/重复查询，5,000 项 / 30 条规则的预处理逐项和批量分类，以及 100 项回溯压力正则。排序、保存和规则耗时上限 1 秒，分配上限分别 32 / 1 / 4 MiB；重复查询上限 100 ms / 1 MiB，首次查询上限 500 ms / 8 MiB。这些是捕获明显退化的自动检查边界，不是面向所有电脑的性能承诺，也不代表进程总内存。

对比优化前后时使用同一电脑、构建配置、SDK 和数据规模，保留两份结果；不要把不同 CI 机器的毫秒差异当作产品提升。降低阈值前先收集多个环境的结果。

第二条还包含 28 项工作进程验收，结果为 `artifacts/verification-0.2.0-beta.5/shell-worker-result.json`。其中记录一次工作进程临时私有内存、挂起请求耗时及排队请求期限；用进程实际退出和后续重启判断恢复，不能只根据 `Task` 已返回判断。工作进程空闲退出后不再占用常驻内存，读取期间有额外进程开销；测试样本不代表真实桌面全部进程的内存变化。隔离边界见[Shell 请求隔离](Shell请求隔离.md)。

第二条检查启动项和图层身份、隐藏属性变化、搜索合并、控件复用、真实目录事件风暴、失联恢复、无变化刷新、引用清理等行为。长测需先提交源码并构建专用验收包：`./scripts/build.ps1 -Verification`。然后运行 `./scripts/start-soak.ps1 -Minutes 480` 冻结本次二进制并创建隔离运行，再用 `./scripts/check-soak.ps1 -RunPath <run.json路径>` 核验进程身份、版本、哈希、90 秒内心跳和最终结果。没有最终结果不算通过；睡眠或停顿不按正常观察时长累计。启动前拒绝未提交或正式构建，不模拟输入、不接管桌面、不显示任务栏。

每 30 秒追加 `resources.jsonl`，包含私有内存、工作集、句柄、CPU、托管内存和 GC 次数。排除最初 15 分钟，并取得至少 15 分钟观察后，检查脚本报告资源范围和趋势；CPU 百分比按一个核心的占用口径，不包含其他工作进程。趋势是观察值，尚无跨环境泄漏判定标准。脚本有 9 项虚构状态检查，防止旧结果、错误进程/版本/时长、哈希变化或半写入 JSON 被记为通过。

2026-10-06 同机 Release、1 万文件合成数据，60 个分区重复搜索优化前 41.17 ms / 15,471,704 B，优化后 1.13 ms / 98,888 B；首次查询 7.29 ms / 2,282,984 B。重复查询会复用排序，首次查询包含建立分组与排序的工作。缓存限制为最多 25,000 项文件引用及对应排序引用，超大或大量重叠映射只临时处理；不保留历次查询结果。结果位于本地 `artifacts/query-before.json` / `query-after.json`。

完整性能验收仍应补充真实桌面空闲 CPU、内存/句柄趋势及多屏操作响应。屏幕外验收不能代替这些测量。
