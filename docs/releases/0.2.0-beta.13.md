# Lume 0.2.0-beta.13

此预览版在 PDF 渲染前限制目标尺寸，降低超长页面预览持有的像素数据，并补齐翻页与关闭检查。

- PDF 页面目标宽度最多 1200、高度最多 2400 像素，按裁切和旋转后的整页比例缩放；普通页面继续以 1200 像素宽度渲染，超长页缩小整页，翻页行为保留。
- 同机 Release、实际隐藏预览控件中的 400×4000 点临时 PDF，返回位图从 1200×12000 / 57,600,000 B 降至 240×2400 / 2,304,000 B（54.93 → 2.20 MiB，像素数据减少 96%）。这是受控页面样例，不代表整个进程占用、PDF 解析峰值或所有文档的渲染速度。
- 使用系统提供的裁切、旋转后尺寸计算渲染宽高，参见 [PdfPage.Size](https://learn.microsoft.com/en-us/uwp/api/windows.data.pdf.pdfpage.size?view=winrt-26100)。渲染后的 32 MiB 编码结果检查继续保留，不能代替渲染前尺寸限制。
- 新增 35 项检查，覆盖普通、超长、超宽、旋转和裁切页面的实际像素、颜色、冻结及跨线程读取；实际预览控件核对双向翻页、首尾边界、原件哈希、加载中关闭、损坏文件和取消。不显示窗口、不创建句柄、不附着 Explorer 或模拟输入。
- 关闭窗口后不提交迟到的页面或把完成的文档加载重新写入窗口。已开始的原生渲染仍可能继续到完成，完成后的流和页面按作用域释放。
- 完整/精简包各拒绝 10 个验收入口，共 20 项实际进程检查；36 项错误包回归继续执行。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。系统支持范围见随包《支持与已知问题.md》，下载校验和 GitHub 来源证明见《验证下载.md》。来源证明不替代 Windows 代码签名。

仍为预览版。真实 Explorer 重启、休眠、多屏 / 混合缩放、读屏与键盘焦点，以及本版完整 8 小时常驻验收尚未完成；此前版本的长测不计作本版通过。稳定版保持 0.1.0。本轮未升级或重启用户正在使用的程序。
