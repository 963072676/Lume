# 2026 年 10 月复盘与优化

本次复盘更新至 0.2.0-beta.5。已补齐升级恢复、计算响应、慢 Shell 请求隔离、过期引用清理及大目录查询；保持预览版，尚不足以声明所有 Windows 桌面场景已稳定。

## 已完成

| 原问题 | 当前行为与验证 |
| --- | --- |
| 解压新版本后可能仍唤起旧目录程序，启动项也保留旧路径 | “关于”显示实际运行信息；发现另一目录的实例时显示旧版本与路径；已有启动项先备份再迁移，未知或关闭的启动项保持原状。隔离注册表验证 |
| 仅备份主配置不能覆盖分段历史和 AI 设置 | 完整 ZIP 包含配置、设置、历史及归档日志；恢复前验证清单、哈希和依赖，保留当前整份目录后替换。跨分段历史、篡改、缺失依赖和路径越界回归 |
| 单条损坏归档 JSON 会中断整个恢复 | 有效备份优先；保留损坏原件；双损坏记录隔离，不影响其他批次。恢复仅核对文件状态，不自动删除或移动文件 |
| 每次文件匹配反复拆分扩展名与关键词，复杂正则累计占用 UI | 条件预处理和兼容正则缓存；扫描分类、保存规则、预览后台执行；默认 2 秒整批计算限额，取消或过期结果不提交。写入失败和并发变更回归 |
| 搜索逐字重建页面；隐藏属性变化未及时刷新；事件风暴持续推迟同步 | 输入等待 140 ms 后合并刷新，监控属性变化，事件持续到达时约 2 秒后停止延期。真实文件属性和事件回归 |
| 图层隐藏缺少完整身份校验，窗口重挂载/工作区变化难以及时发现 | 隐藏与恢复校验句柄、PID 和类名，保留损坏租约；缓存读取并保留低频校验；健康检查增加父窗口、工作区和 DPI。屏幕外窗口验证 |
| Shell 图标/快捷目标调用卡住后，后台线程无法终止 | beta.4 用独立 STA 进程、包含排队的请求期限和有限容量；卡死确认终止，冷却后重建，空闲 10 秒退出。28 项非交互检查验证 Dispatcher 响应、真实进程退出及恢复 |
| 导入快捷方式和应用 AI 建议同步核对目标 | 手动引用先保存，目标后台补齐；AI 后台核对后再提交，取消/超时/过期结果不写入。目标读取失败暂时保留已有归类，手动操作与撤销优先 |
| 失踪文件的自动归类和学习样本长期留在状态中 | beta.5 提供默认 30 天的缺失等待、预览、完整备份、复检和清理；手动固定、排序、外部引用及无法确认路径保留。新格式保护重启和归档历史中的撤销，回退须恢复清理前备份 |
| 每个分区重复遍历文件，搜索后重新创建本页所有控件 | 一次分组并复用排序，缓存限制为 25,000 项文件引用及对应排序；只复用当前页最多 80 个控件，筛选、元数据、主题和选择变化回归 |
| 长测缺少逐次资源证据，旧结果可能被误读为成功 | 冻结已提交验收构建，记录内存/句柄/CPU/GC，验证心跳、进程、构建、哈希及有效时长；9 项状态脚本回归。当前进行中的运行不算通过 |

折叠卡片在 beta.2 已不会创建文件图块；本次只进一步提前跳过分页和签名计算，不能把此前误判当作新增大幅性能提升。

## 性能证据

Windows 11、.NET 10.0.11、Release、同机合成数据的单次前后诊断：

| 场景 | beta.2 | 本次实现 |
| --- | ---: | ---: |
| 5,000 文件 / 30 条未匹配扩展名规则，预热后逐项匹配 | 182.18 ms / 112.31 MiB 临时分配 | 22.50 ms / 88 B 临时分配 |
| 100 个 121 字符名称，`^(a+)+$` 压力正则 | 6,241.10 ms | 32.03 ms，含首次准备 |

这些是受控计算样例，不能推出真实进程总内存、所有正则或所有机器的提升幅度。新的 7 次采样基准还测量批量匹配，使用源码中的宽松退化门槛；运行方法见[性能复测](性能复测.md)。后向引用和环视等不支持线性引擎的正则仍沿用带超时的兼容引擎。

beta.5 的同机查询基准：1 万文件 / 60 分区重复搜索，41.17 ms / 14.75 MiB 临时托管分配降到 1.13 ms / 0.094 MiB；首次查询 7.29 ms / 2.18 MiB。缓存不保留历次搜索结果，超出引用上限时临时处理。减少当前状态中的路径记录不等于删除备份和撤销数据，不能声称磁盘总占用同步下降。

| 高 | 真实桌面稳定性验收 | 虚构桌面文件下验证 Explorer 重启、休眠、多屏插拔/混合缩放、正常/异常退出；运行完整 8 小时并保留最终结果和资源趋势 |
| 中 | 扩展真实规模测量 | 当前已验证 1 万文件的跨分区查询及 1,000 项事件/控件复用；继续检查大量重叠映射、命令面板和更大目录。实际键盘焦点与读屏仍需人工验收 |
| 中 | 开源使用体验 | 补当前主题截图、故障流程、键盘/读屏检查，以及新用户从下载到首次整理的实机记录 |
| 后续 | 签名与更多平台 | 明确证书成本、发布密钥管理、ARM64 / 更多系统的实机验证；当前不宣称已签名或已支持 |

不因本次计算提速就取消健康兜底或宣布稳定版本。手动清理旧包前，应核对运行路径、启动项、菜单注册和回退需求。
