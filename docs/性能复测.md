# 性能复测

在与构建相同的 Windows / PowerShell 7 环境运行：

```powershell
./scripts/benchmark.ps1
./scripts/verify.ps1 -SkipInteractive
```

第一条写出 `artifacts/benchmark.json`，使用虚构数据，预热 2 次并测量 7 次中位数。记录系统、运行时、处理器数量、耗时及当前线程托管分配，不包含个人路径。共 21 个场景：排序 5,000/10,000 项，设置保存 0/1,000 条历史，1 万文件在 5/30/60 个分区的首次/重复查询，5,000 项 / 30 条规则的预处理逐项和批量分类，100 项回溯压力正则，以及 1 万/10 万文件的有界搜索命中和无匹配场景，以及 1 万文件 / 60 同根映射的一分区/全部分区首次与重复查询。排序、保存和规则耗时上限 1 秒，分配上限分别 32 / 1 / 4 MiB；重复查询上限 100 ms / 1 MiB，首次查询上限 500 ms / 8 MiB；有界文件搜索上限 250 ms / 16 KiB。这些是捕获明显退化的自动检查边界，不是面向所有电脑的性能承诺，也不代表进程总内存。

对比优化前后时使用同一电脑、构建配置、SDK 和数据规模，保留两份结果；不要把不同 CI 机器的毫秒差异当作产品提升。降低阈值前先收集多个环境的结果。

第二条还包含 28 项工作进程验收，结果为 `artifacts/verification-0.2.0-beta.7/shell-worker-result.json`。其中记录一次工作进程临时私有内存、挂起请求耗时及排队请求期限；用进程实际退出和后续重启判断恢复，不能只根据 `Task` 已返回判断。工作进程空闲退出后不再占用常驻内存，读取期间有额外进程开销；测试样本不代表真实桌面全部进程的内存变化。隔离边界见[Shell 请求隔离](Shell请求隔离.md)。

第二条检查启动项和图层身份、隐藏属性变化、搜索合并、控件复用、真实目录事件风暴、失联恢复、无变化刷新、引用清理等行为。长测需先提交源码并构建专用验收包：`./scripts/build.ps1 -Verification`。然后运行 `./scripts/start-soak.ps1 -Minutes 480` 冻结本次二进制并创建隔离运行，再用 `./scripts/check-soak.ps1 -RunPath <run.json路径>` 核验进程身份、版本、哈希、90 秒内心跳和最终结果。没有最终结果不算通过；睡眠或停顿不按正常观察时长累计。启动前拒绝未提交或正式构建，不模拟输入、不接管桌面、不显示任务栏。

每 30 秒追加 `resources.jsonl`，包含私有内存、工作集、句柄、CPU、托管内存和 GC 次数。排除最初 15 分钟，并取得至少 15 分钟观察后，检查脚本报告资源范围和趋势；CPU 百分比按一个核心的占用口径，不包含其他工作进程。趋势是观察值，尚无跨环境泄漏判定标准。脚本有 16 项虚构状态检查，防止旧结果、缺少构建身份、错误进程/版本/时长、字符串成功标志、超过实际经过时间、哈希变化或半写入 JSON 被记为通过。

2026-10-06 同机 Release、1 万文件合成数据，60 个分区重复搜索优化前 41.17 ms / 15,471,704 B，优化后 1.13 ms / 98,888 B；首次查询 7.29 ms / 2,282,984 B。重复查询会复用排序，首次查询包含建立分组与排序的工作。缓存限制为最多 25,000 项文件引用及对应排序引用，超大或大量重叠映射只临时处理；不保留历次查询结果。结果位于本地 `artifacts/query-before.json` / `query-after.json`。

beta.6 的同机有界文件查询，无匹配时 1 万文件为 0.24 ms / 584 B，原逐项拆分为 1.95 ms / 1,120,144 B；十万文件为 1.37 ms / 584 B，原逐项拆分为 19.21 ms / 11,200,144 B。命中达到上限后只再确认一项额外结果，不继续遍历剩余命中项。计时不包含线程池调度、140 ms 合并或 UI 渲染。新增 18 项隔离面板检查验证 Dispatcher 响应、取消与执行有效性；辅助名称检查不能替代真实焦点和读屏验收。结果为 `palette-result.json`。

beta.7 同机同一压力配置（1 万文件 / 60 同根映射，含收件箱共 61 分区），全部映射重复查询由 254.21 ms / 43,981,224 B 降至 0.26 ms / 94,576 B；首轮由 252.31 ms / 43,981,048 B 降至 7.46 ms / 2,485,408 B。只查一个映射重复查询为 0.25 ms / 84,696 B。前后结果为本地 `artifacts/query-scale-before.json` / `query-scale-after.json`；基准另含 5 个默认分区，其数值可不同。索引按唯一桶计数，排序按唯一视图计数，各自上限 25,000 项引用；不同排序超限继续临时计算。十万普通文件仍超过缓存范围，需要完整临时查询，当前样本不作为真实桌面性能承诺。

完整性能验收仍应补充真实桌面空闲 CPU、内存/句柄趋势及多屏操作响应。屏幕外验收不能代替这些测量。
