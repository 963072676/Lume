# Lume 0.2.0-beta.3

本版补齐升级与完整数据恢复，并减少规则和搜索的重复工作。设置增加“关于”，能核对实际运行版本与程序路径；已启用的 Lume 启动项先备份再迁移。旧状态首次升级前自动生成完整 ZIP 备份，避免只保存 `state.json` 遗漏分段历史。

完整备份含规则、分区、布局、全部历史、归档记录及账户加密的 AI 设置。恢复先检查清单、容量、SHA-256 和历史依赖，再退出重启并保留当前整份目录；备份不含真实桌面文件，恢复配置不会逆转物理归档。损坏归档日志从有效备份恢复并保留原件，双损坏记录隔离提示。

规则条件预处理并缓存正则；扫描归类、规则保存与预览后台执行，支持取消、整批限额和过期结果拒绝。搜索输入合并，隐藏属性实时刷新，事件风暴不再无限延期。桌面图层操作校验 PID 与类名，健康检查增加父窗口、工作区及 DPI。

## 下载与升级

Windows x64 完整 ZIP 自带运行时；`-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。先退出旧版并确认原桌面恢复，备份整个 `%LOCALAPPDATA%\Lume`，解压新包到新目录并保留 `Lume.Guard.exe`。从 beta.1 / beta.2 升级不改变状态格式。从 0.1.0 升级会先完整备份再迁移到格式 2，旧版无法直接读取新数据。详见[升级与回退](https://github.com/963072676/Lume/blob/v0.2.0-beta.3/docs/升级与回退.md)。每个 ZIP 均附 SHA-256。

## 验收范围

本地核心 127 项、隔离启动项与托管图层 16 项、实时刷新与性能行为 13 项以及 7 场景性能基准通过；原生恢复 8 场景、菜单、图标状态和非交互主界面也通过。Windows 11 本地非交互功能预览通过；服务器 CI 仍按已知限制跳过该阶段，记录覆盖范围。本轮未移动真实鼠标或进行完整桌面交互验收。

同机合成测试的 5,000 文件 / 30 条规则逐项匹配从约 182 ms 降至 22 ms；压力正则样例从约 6.24 秒降至 32 ms。数据只代表指定计算样例，不是全程序内存或所有机器的性能承诺。

真实 Explorer 重启、休眠、多屏插拔/缩放及完整 8 小时常驻验收仍未完成，慢 Shell 请求的进程隔离也待后续实现。因此本版保持预览，稳定版仍为 0.1.0。完整备份和历史含真实路径，请私下保管，问题报告只附经检查的脱敏诊断。
