# 快速操作与搜索

在管理窗口按 Ctrl+K 或点击“快速操作”。输入文件名称、分区名称或操作名称，用 ↑ / ↓ 选择，Enter 执行，Esc 关闭。`>刷新` 只查找操作，可用于刷新、打开设置或显示整理历史。

文件支持多个关键词，每个关键词都需要在名称或来源中匹配。`报告 txt` 查找包含“报告”且名称或来源包含“txt”的文件；`微信 png` 同时匹配文件名称与推测来源；`项目 文件夹` 可缩小到项目文件夹。大小写不影响匹配，空格、制表符、换行及全角空格均可分隔关键词。分区和操作按输入文字匹配名称或说明。

快速操作覆盖当前已经扫描的关注目录、映射目录和外部文件引用；不建立全盘索引。每次最多显示 20 个分区和 40 个文件，超过时显示“结果较多”，请增加关键词缩小范围。操作列表按匹配项显示。文件路径保留在提示和辅助信息中。

主窗口与桌面分区的搜索作用于当前视图和选中分区，覆盖该范围所有页，每页 80 项，可翻页；最近文件分区本身只包含最近修改的 40 个文件。快速操作的结果上限与文件视图的分页是不同设置。

连续输入等待约 140 ms 后合并查询。搜索尚未完成时，Enter 会等待当前查询；刚输入的新关键词不会执行之前显示的结果。关闭面板会取消待查询，↑ / ↓ 操作在当前结果中选择。

自动检查验证查询合并、扫描/分区变化、过期结果、重复执行、辅助名称和关闭取消。真实键盘焦点、输入法组合输入和读屏体验尚需人工验收，不能由屏幕外程序检查替代。
