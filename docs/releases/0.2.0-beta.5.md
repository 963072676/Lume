# Lume 0.2.0-beta.5

预览版。本次增加过期引用清理，降低大目录重复搜索的耗时与分配，并完善非交互长测记录。

- “设置 → AI 与数据”可检测已删除文件的自动归类记录与学习样本。默认等待 30 天，先预览、完整备份、再复检和清理；保护手动固定、排序、外部引用及无法确认的路径，可重启后或跨历史分段撤销。
- 1 万文件的跨分区查询一次分组，按当前扫描和配置版本复用排序；缓存最多保留 25,000 项文件引用及对应排序引用。管理窗口只复用当前页最多 80 个控件，筛选后释放不可见项目。
- 同机 Release 合成数据，60 个分区重复搜索从约 41.17 ms / 14.75 MiB 临时托管分配降到 1.13 ms / 0.094 MiB；首次查询约 7.29 ms。这是受控搜索基准，不是进程总内存或全部机器的承诺。
- 长测冻结构建、记录逐次内存/句柄/CPU/GC，核验心跳、进程身份、版本、哈希及有效运行时长。验收窗口不显示任务栏；显式非交互检查不模拟键鼠。
- 新增 23 项核心回归、22 项清理窗口检查和 9 项长测状态脚本检查。完整自动检查与本地功能预览通过后发布。
- GitHub 标签发布为两个 ZIP 生成构建来源证明，提供校验说明；这不替代 Windows 代码签名。

## 下载

`Lume-0.2.0-beta.5-win-x64.zip` 为自带运行环境的完整便携版；`Lume-0.2.0-beta.5-win-x64-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。解压到新目录，退出旧版本后启动，保留全部随包文件。

## 数据与回退

读取格式 1 / 2 / 3。首次旧格式迁移先完整备份；本次只有执行过期引用清理才升级为格式 3。beta.1–beta.4 不能直接读取清理后的状态，回退应先在本版恢复清理前 `.lume-backup.zip`。完整备份不包含真实桌面文件，不撤销物理归档。详见随包《升级与回退.md》《过期引用清理.md》。

## 验收边界

8 小时隔离运行仍在观察，未将正在进行的长测记为通过。旧 beta.4 基线也不作为本版验收。Explorer 重启、真实休眠、多屏插拔/混合缩放和完整真实桌面稳定性仍待实机验证。发布流程保持预览版，不替换 0.1.0 稳定版下载；没有代码签名或 ARM64 原生包。
