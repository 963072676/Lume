# Lume 0.2.0-beta.11

此预览版限制壁纸回退图的长期缓存，减少桌面卡片刷新时重复读取壁纸来源，并修复更新同路径壁纸后仍显示旧图的问题。

- 壁纸回退缓存最多保留 8 张位图、32 MiB 像素数据，按最近访问淘汰；来源改变或缺失、卡片关闭时清空。已显示卡片继续持有所需图像，超限单图可以显示但不长期缓存，此限额不代表整个进程内存上限。
- 壁纸路径未变而文件时间已更新时，重新读取实际像素；同一来源的其他尺寸继续复用 WPF 解码。卡片位置、裁切、四分之一尺寸渲染、主题与原生玻璃保留，移除未使用的亮度采样。
- 普通和系统卡片初始化、整批刷新共用一次来源读取；初始化来源首次使用后释放，独立更新仍读取当前来源。
- Windows 11 / .NET 10.0.11、Release、64 种模拟显示器尺寸的实际 WPF 渲染中，缓存持有像素由 52,359,168 B / 64 张降至 8,939,008 B / 8 张（49.93 → 8.53 MiB）。这是受控缓存容量观察，不代表真实显示器切换、整个进程内存或渲染速度的同等改善。
- 新增 24 项壁纸检查，验证冻结图像、淘汰/像素容量、同路径实际颜色更新、缺失恢复、负坐标裁切，以及实际普通/系统卡片来源共享。测试只使用临时图片和自身隐藏宿主，不显示窗口、不附着 Explorer、不模拟输入或更改真实壁纸。
- 发布包上传前增加 36 项合成包回归，核对来源、版本、字段类型、清单、哈希和运行环境；完整/精简包的 8 个验收入口均须拒绝，共 16 项实际进程检查。修正空闲工作进程验收中的异步清理竞争，仍要求实际进程退出及客户端清理在原期限内完成。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。系统支持范围见随包《支持与已知问题.md》，下载校验和 GitHub 来源证明见《验证下载.md》。来源证明不替代 Windows 代码签名。

仍为预览版。本版真实 Explorer 重启、休眠、多屏 / 混合缩放、读屏与键盘焦点，以及完整 8 小时常驻验收尚未完成；此前版本的长测不计作本版通过。稳定版保持 0.1.0。本轮未升级或重启用户正在使用的程序。
