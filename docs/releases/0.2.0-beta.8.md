# Lume 0.2.0-beta.8

此预览版改善表单与文件图块的辅助信息，修正键盘打开菜单的位置。保留 beta.7 的大目录查询与 beta.6 的后台快速搜索优化。

- 归档、规则及 AI 配置输入关联可读取的字段名称；标签变化同步更新，保留已有帮助与密码输入语义。
- 规则条件切换时更新匹配方式和值的用途名称。文件图块提供完整路径与当前选中状态，搜索提供名称和快捷键。
- 用键盘打开文件或系统入口菜单时定位到对应图块；鼠标打开菜单沿用鼠标位置。
- 文件图块的辅助执行入口调用文件打开回调；普通单击仍只选择，禁用、隐藏或排队后失去可用性的图块不执行。
- 新增 32 项非交互 WPF 自动化属性、执行回调和屏幕定位检查，纳入自动验收。没有模拟实际键鼠、执行读屏软件、实际打开文件或弹出原生菜单，不等于这些实机场景已通过。
- 下载入口指向发布页面实际已有附件，区分源码版本与已发布包。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。SHA-256 和 GitHub 来源证明验证方法见随包《验证下载.md》，来源证明不替代代码签名。

仍为预览版。真实 Explorer 重启、休眠、多屏/混合缩放、读屏与键盘焦点，以及完整 8 小时桌面常驻验收尚未完成；当前长测不计作通过。既有 beta.5 主题截图使用演示文件。
