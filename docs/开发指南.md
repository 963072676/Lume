# 开发指南

## 目录

| 路径 | 用途 |
| --- | --- |
| `src/Lume.Core` | 扫描、规则、状态、布局、AI 请求与归档 |
| `src/Lume.Desktop` | WPF 界面、桌面分区、托盘与 Windows 集成 |
| `src/Lume.Shell` | C++ 原生桌面右键菜单 |
| `tests/Lume.Core.Tests` | 无外部测试框架的核心回归程序 |
| `tests/Lume.Desktop.Verification` | 仅验收包编译的界面与桌面检查 |
| `scripts` | 构建、验收、打包与菜单诊断 |

产品直接使用 .NET / Windows API，没有第三方 UI 框架。桌面菜单命令从 C# 清单生成到 C++，避免两端漂移。
主窗口按文件、规则与历史、设置分开维护；共享控件样式位于 `Styles.xaml`。

## 构建与检查

环境要求见 [README](../README.md)。所有命令在仓库根目录的 PowerShell 7 中执行。

```powershell
dotnet run --project tests/Lume.Core.Tests -c Release
./scripts/build.ps1
./scripts/build.ps1 -FrameworkDependent
./scripts/verify.ps1 -SkipInteractive
./scripts/verify.ps1
./scripts/package.ps1
./scripts/package.ps1 -FrameworkDependent
```

`verify.ps1` 构建独立验收包，执行核心、菜单、图标、功能、界面和桌面交互检查。
`-SkipInteractive` 跳过真实鼠标悬停与桌面交互，适用于自动构建环境，不能替代完整桌面验收。
结果保存在 `artifacts/verification-<版本>/`；截图与独立运行数据位于 `artifacts/verification-app/`。
正式构建不包含 `EnableVerification=true` 的测试入口。

`--demo --action settings` 可查看演示管理界面，数据位于程序旁 `demo-data`。演示仍会临时挂载真实桌面；退出恢复桌面。
同一时间只运行一个管理桌面的实例。请勿在重要桌面操作期间执行交互验收。

## 版本与发布

`Directory.Build.props` 是程序版本和构建脚本的共同来源。调整版本时同步说明文档与 `app.manifest` 中四段式程序集版本。
GitHub Actions 在推送和 Pull Request 时运行核心回归、原生菜单及两种正式包构建；真实桌面验收在本地执行。
提交前验证 `git diff --check`。发布时为已验证提交创建 `v<版本>` 标签，在 Releases 上传两个 ZIP 与各自 `.sha256` 文件。
打包只读取 `release-files.txt` 中的分发文件，不带演示数据、测试输出或调试符号。

## 数据兼容与本地文件

程序版本与状态格式版本独立；当前状态格式仍为 1。调整状态结构时需要兼容已有数据。
真实运行数据位于 `%LOCALAPPDATA%\Lume`，不属于源码仓库。
`.gitignore` 保留本地 SDK、构建产物、工具状态与诊断文件在本机使用，同时排除它们进入 Git。
排除规则无法取代提交审查，公开前仍应检查凭据、个人路径与截图内容。
