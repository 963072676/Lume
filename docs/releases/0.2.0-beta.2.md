# Lume 0.2.0-beta.2

这是图标状态修复预览版。此前清空回收站后，Lume 系统入口可能仍显示满回收站图标；现在常驻进程接收 Shell 变化通知，后台查询项目数后更新空/满图标和提示。快捷方式的自定义图标资源、目标文件与文件关联变化也会使相关缓存失效；Shell 未返回资源位置时，独立 `.ico` 文件变化仍有兜底刷新。系统入口仍是 Windows 桌面图标设置中的五项。

## 下载与升级

Windows x64 完整 ZIP 自带运行时；`-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。先从托盘退出旧版，确认原桌面恢复，备份整个 `%LOCALAPPDATA%\Lume`，将新包解压到新目录并保留 `Lume.Guard.exe`。从 beta.1 升级不改变数据格式；从 0.1.0 升级仍会迁移状态，旧版不能直接读取迁移后的数据。详细步骤见 [升级与回退](https://github.com/963072676/Lume/blob/v0.2.0-beta.2/docs/升级与回退.md)。每个 ZIP 的 SHA-256 见同名 `.sha256` 附件。

## 验收边界

发布流水线检查核心 111 项、图标状态 29 项、原生恢复、菜单、主界面、目录恢复与性能，并构建完整和精简包。Windows 11 本地功能预览验收通过；Windows Server 构建机仍按已知限制跳过该阶段。图标测试使用真实 Shell 通知和注入的回收站项目数，没有清空用户真实回收站；真实 Explorer 桌面接管、休眠、多屏插拔/缩放和完整 8 小时常驻也未完成。因此本版保持预览状态，稳定版仍为 0.1.0。
