# Lume 0.2.0-beta.4

本版将快捷目标、文件/媒体图标和系统入口图标读取移至可终止的独立工作进程。请求有包含排队时间的期限；卡死或崩溃时返回备用图标，冷却后可重新建立连接。工作进程空闲 10 秒后退出，关闭 Lume 后不会长期残留。复用同一程序，不新增运行时安装要求。

快捷目标每轮读取预算 8 秒，失败保留文件、有效旧信息与已有归类，并提示后续重试。手动导入先保存引用，AI 建议应用前在后台核对文件；取消、超时或期间发生修改时整批不提交，撤销继续可用。数据格式仍为 2。

## 下载与升级

Windows x64 完整 ZIP 自带运行时；`-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。每个 ZIP 附 SHA-256。先从托盘退出旧版、备份整个数据目录，再解压新包到新目录，保留全部随包文件。详见[升级与回退](https://github.com/963072676/Lume/blob/v0.2.0-beta.4/docs/升级与回退.md)。从 beta.1 / beta.2 / beta.3 升级不改变数据格式。

## 验收范围

核心 136 项、工作进程 28 项，以及原生恢复 8 场景、隔离启动项/图层、菜单、图标、非交互功能预览、主界面与性能行为通过本地验收。工作进程检查含无限挂起、真实进程退出、冷却重启、排队期限、父进程强制退出、空闲回收和界面响应；测试未接管真实桌面或模拟输入。服务器 CI 按已知限制跳过功能预览并记录覆盖范围。

本版主要改善卡死恢复能力；独立进程有短时额外内存及启动成本，空闲后释放，不承诺主程序常驻内存下降。隔离范围不含目录枚举、正文预览及原生右键菜单的所有调用。真实 Explorer 重启、休眠、多屏和完整 8 小时验收仍未完成，保持预览版，稳定版仍为 0.1.0。
