# Lume 0.2.0-beta.9

此预览版减少超大普通目录查询的临时分配，并补齐系统范围与构建依赖维护说明。保留 beta.8 的辅助信息、beta.7 的共享映射查询和 beta.6 的后台快速搜索。

- 没有目录映射时不再逐文件生成父目录字符串；名称排序只生成一组排序键，同名文件继续保留扫描先后。其他排序方式保持原有规则。
- 同机 Windows 11 / .NET 10.0.11、Release、7 次采样，十万文件 / 60 普通分区全部命中查询的临时托管分配从 24,064,096 B 降至 5,652,096 B（22.95 → 5.39 MiB），减少约 76.5%。这是受控核心函数测量，不等于整个进程内存降低 76.5%，也不保证所有环境同等提速。
- 超出缓存范围仍临时处理；索引和排序缓存分别维持 25,000 项文件引用上限。新增同名稳定顺序及超大普通分区快照/扫描更新回归，核心检查共 174 项；性能基准增加两个十万文件场景，共 23 场景。
- 系统说明区分编译 API 目标、运行时支持和实机验收。推荐使用仍在 [.NET 10 支持清单](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md#windows)内的 Windows 11 x64；Windows 10 需核对具体版本与企业 / LTSC 类型，完整包自带运行时不扩大系统支持范围。
- 5 个官方 GitHub Action 固定到核对过的完整提交，配置每周依赖更新检查。构建检查、包清单、SHA-256 和来源证明继续作为发布条件。
- 收紧验收报告：必须包含真正的布尔值 `passed=true`，缺字段、字符串、数值、数组或截断报告不算通过。13 项虚构 JSON 检查纳入自动验收。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。下载校验和来源证明验证方法见随包《验证下载.md》；来源证明不替代 Windows 代码签名。

仍为预览版。非交互检查没有模拟键鼠、接管真实桌面或重启用户程序。真实 Explorer 重启、休眠、多屏 / 混合缩放、读屏与键盘焦点，以及完整 8 小时常驻验收尚未完成；进行中的长测不计作通过。稳定版仍为 0.1.0。
