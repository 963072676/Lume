# 性能复测

在与构建相同的 Windows / PowerShell 7 环境运行：

```powershell
./scripts/benchmark.ps1
./scripts/verify.ps1 -SkipInteractive
```

第一条写出 `artifacts/benchmark.json`，使用虚构数据，预热 2 次并测量 7 次中位数。记录系统、运行时、处理器数量、耗时及当前线程托管分配，不包含个人路径。排序分别测量 5,000/10,000 项；设置保存分别使用 0/1,000 条历史。每场景耗时上限 1 秒；排序分配上限 32 MiB，设置保存分配上限 1 MiB。这些是捕获明显退化的宽松自动检查边界，不是面向所有电脑的性能承诺，也不代表进程总内存。

对比优化前后时使用同一电脑、构建配置、SDK 和数据规模，保留两份结果；不要把不同 CI 机器的毫秒差异当作产品提升。降低阈值前先收集多个环境的结果。

第二条检查真实目录事件风暴、失联恢复、无变化刷新等行为。长测先运行 `./scripts/start-soak.ps1 -Minutes 480` 创建隔离运行，再用 `./scripts/check-soak.ps1 -RunPath <run.json路径>` 核验进程身份、哈希和最终结果。没有最终结果不算通过；睡眠或停顿不按正常观察时长累计。

目前长测记录内存和句柄，但尚未建立跨环境的泄漏趋势判定标准。完整性能验收仍应补充真实桌面空闲 CPU、内存/句柄趋势及多屏操作响应。屏幕外验收不能代替这些测量。
