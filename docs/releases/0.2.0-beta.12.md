# Lume 0.2.0-beta.12

此预览版减少长图预览持有的像素数据，保留画面比例，并完善图像读取与验收报告的生命周期。

- 图片预览按长边最多 1600 像素解码，小图保持原尺寸；保留实际颜色、比例及冻结图像，完成或失败均关闭源文件，不改写原件。预先取消不读取图像，关闭预览后丢弃过期结果。
- Windows 11 / .NET 10.0.11、Release、实际隐藏预览控件中，2000×6000 PNG 的返回图像由 1600×4800 / 30,720,000 B 像素变为 533×1600 / 3,411,200 B（29.30 → 3.25 MiB，约减少 88.9%）。这是受控返回位图测量，不代表所有格式的解码峰值、整个进程占用或速度提升。
- PNG / JPEG 可按目标尺寸解码；其他编解码器可能先完整解码再缩小，参见 [WPF 解码说明](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.imaging.bitmapimage.decodepixelwidth?view=windowsdesktop-10.0)。已开始的原生解码无法由取消检查中断，文件大小限制继续保留。
- 新增 25 项无窗口图像检查，覆盖横图、长图、方图、小图、实际颜色、比例、冻结、文件释放、原件哈希、同路径替换、缺失、损坏和取消。实际预览另在不显示、不创建句柄的独立控件中核对，没有发送键鼠输入或附着 Explorer。
- 完整/精简包均须拒绝 9 个验收入口，共 18 项实际进程检查；36 项错误包回归继续执行。退出保护验收报告写完、关闭后再发布，避免父进程读取未完成的 JSON，身份检查和期限保持不变。

不改变数据格式。可读取格式 1 / 2 / 3；只有执行过期引用清理才升级为 3，回到 beta.1–beta.4 前须恢复清理前完整备份。升级方法见随包《升级与回退.md》。

完整包解压后可运行；精简版需要 .NET 10 Windows Desktop Runtime x64。系统支持范围见随包《支持与已知问题.md》，下载校验和 GitHub 来源证明见《验证下载.md》。来源证明不替代 Windows 代码签名。

仍为预览版。真实 Explorer 重启、休眠、多屏 / 混合缩放、读屏与键盘焦点及本版完整 8 小时常驻验收尚未完成；此前版本的长测不计作本版通过。稳定版保持 0.1.0。本轮未升级或重启用户正在使用的程序。
