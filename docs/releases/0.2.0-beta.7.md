# Lume 0.2.0-beta.7

预览版。本次减少共享目录的重复查询开销，并修复源码构建日志问题。

- 相同映射目录和重复最近分区共享一个文件桶；相同排序与本批筛选共用只读视图。各分区的独立排序、手动顺序、映射与手动固定的重叠可见性保持原有语义。
- 索引与排序分别最多缓存 25,000 项文件引用；不保留历次筛选结果。偏好变化时移除过期排序，多种排序超限或超大目录继续临时计算。
- 同机 Windows 11 / .NET 10.0.11、Release、7 次采样中位数，故意构造的 1 万文件 / 60 同根映射状态，查询全部映射从 254.21 ms / 43,981,224 B 临时分配降至 0.26 ms / 94,576 B；首轮由 252.31 ms / 43,981,048 B 降至 7.46 ms / 2,485,408 B。这是核心函数压力案例，不能推导普通目录、UI 渲染或真实进程总内存的同等提升。
- 原生编译在恢复调用目录后输出日志，外接相对日志路径正常；失败仍保留两个输出流和错误。7 项管道检查及真实 C++ 编译验证，原生 DLL / Guard 哈希保持一致。
- 增加 6 项核心查询回归和 4 个性能场景，总计 172 项核心检查、21 个性能场景；覆盖共享只读结果、独立排序、手动顺序、最近文件、缓存上限和超大目录更新。

## 下载与数据

`Lume-0.2.0-beta.7-win-x64.zip` 自带运行环境；`Lume-0.2.0-beta.7-win-x64-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。两个 GitHub ZIP 附 `.sha256` 并有工作流构建来源证明，见《验证下载.md》。

没有新的数据格式迁移。格式 1 / 2 / 3 的升级与回退边界沿用 beta.5；执行引用清理后，回退到 beta.1–beta.4 仍需清理前完整备份。解压到新目录，退出旧程序后运行，不自动切换正在运行的实例。

## 验收边界

自动验证使用隔离数据和屏幕外无激活窗口，不模拟键鼠或接管 Explorer。正在进行和其他版本的长测不作为本版 8 小时通过记录。真实键盘焦点、输入法组合输入、读屏、Explorer 重启、休眠和多屏仍待人工验收；没有代码签名或 ARM64 原生包，保留 0.1.0 稳定版下载。
