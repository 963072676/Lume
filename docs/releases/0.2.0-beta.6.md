# Lume 0.2.0-beta.6

预览版。本次改进 Ctrl+K 快速操作的响应与结果有效性，不自动切换你正在使用的版本。

- 连续输入合并后在后台查询，关键词仅拆分一次；取消或过期结果不覆盖当前列表，关闭面板会取消查询。
- Enter 等待当前查询后执行，重复执行只触发一次；文件扫描或分区变更后重新核对结果。
- 最多显示 20 个分区和 40 个文件，较多结果提示增加关键词；文件路径有完整提示和辅助名称，键盘操作提示保留。
- 多关键词支持空格、制表符、换行及全角空格；只搜索当前已经扫描的文件，没有全盘索引或长期查询缓存。
- 同机 Windows 11 / .NET 10.0.11、Release、7 次采样，十万文件无匹配查询从 19.21 ms / 11,200,144 B 临时托管分配降至 1.37 ms / 584 B。它衡量有界查询函数，未包含后台调度、140 ms 输入合并或控件渲染，不能推导进程总内存。
- 166 项核心回归、18 项隔离面板检查、17 个性能场景及完整非交互检查通过。长测状态新增身份、类型及经过时长检查，共 16 项；没有将未完成长测标记为通过。

## 下载与数据

`Lume-0.2.0-beta.6-win-x64.zip` 自带运行环境；`Lume-0.2.0-beta.6-win-x64-lite.zip` 需要 .NET 10 Windows Desktop Runtime x64。解压到新目录，退出旧版后运行，保留所有随包文件。两个 GitHub ZIP 均提供 `.sha256` 和构建来源证明，详见《验证下载.md》。

本版沿用格式 1 / 2 / 3 读取，只有过期引用清理才升级为格式 3。回退到 beta.1–beta.4 时需恢复清理前完整备份；本版没有新的数据格式迁移。详见《升级与回退.md》《过期引用清理.md》。

## 验收边界

自动面板检查使用屏幕外、无激活窗口及隔离数据，不模拟键鼠，也不接管 Explorer。真实键盘焦点、输入法组合输入、读屏、Explorer 重启、休眠和多屏混合缩放仍待人工验收。旧版本的进行中长测不能作为本版 8 小时验收；没有代码签名或 ARM64 原生包，预览版保留 0.1.0 稳定版下载。
