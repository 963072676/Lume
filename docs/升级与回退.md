# 升级与回退

0.2.0-beta.2 是预览版。0.2.0 系列预览版读取旧状态格式 1，首次保存迁移为格式 2；0.1.0 不能直接读取迁移后的状态。从 beta.1 升级到 beta.2 不再迁移格式。

## 升级

1. 从托盘退出 Lume，确认桌面恢复；保留旧程序目录。
2. 在资源管理器地址栏打开 `%LOCALAPPDATA%`，复制整个 `Lume` 文件夹到独立备份位置。这里包含配置、历史、AI 设置和归档记录；只复制 `state.json` 不够。
3. 将新 ZIP 解压到新目录，保留全部随包文件，运行 `Lume.exe`。
4. 检查分区、规则、历史与主题。首次迁移保留 `state.json.legacy.bak`；它仅代表迁移当时的配置，不含后续操作。

格式 2 的状态依赖 `state.json*` 文件及 `state.json.history` 目录，不要单独清理这些文件。Windows 当前用户加密的 AI 密钥不保证跨电脑、跨账户可用，迁移后可重新填写。

## 回退

退出新程序，先额外备份当前整个数据目录，保留升级后产生的记录。将升级前的整个数据备份恢复到 `%LOCALAPPDATA%\Lume`，再启动旧程序。

回退会回到备份时的配置和历史；升级后新增的记录留在新格式备份中，不能由旧程序读取。物理归档涉及真实文件移动：回退配置不会逆转磁盘操作。若升级后执行过物理归档，请先在新程序中核查归档与恢复记录，避免旧记录和实际文件位置不一致。

## 配置损坏

启动提示恢复时，程序会先校验备份并保留损坏原件；也可在设置页使用恢复功能。没有有效备份时，保留整个目录并提交脱敏诊断，不要反复删除状态文件。历史导出含真实路径，不应上传公开 Issue。
